# Demo Guardrails

## Hackathon Note

This hackathon version should not spend too much time on production compliance. Keep simple guardrails so the demo feels responsible, then focus on the product loop.

## Simple Rules

- Do not use threats.
- Do not insult or shame the borrower.
- Do not talk about police, lawsuits, or criminal consequences.
- If borrower says "wrong person", mark wrong contact.
- If borrower disputes the debt, route to human review.
- If borrower says they cannot pay, offer a smaller payment, installment, or follow-up date.
- If borrower asks for a discount, use the demo max discount rule.

## Demo Maxims

- Be firm on collecting payment.
- Be flexible on timing and plan.
- Be respectful in wording.
- Keep a transcript.
- Show why the agent chose the next action.

## Demo Log

Every conversation should show:

- Borrower.
- Timestamp.
- Channel.
- Offer shown.
- Payment link generated.
- Memory learned.
- Next scheduled action.

## Nice-to-Have Dashboard
