# SettleWise Specs

SettleWise is a hackathon prototype for an AI collections agent. It takes a small borrower/debt database, runs a voice conversation to negotiate repayment, sends SMS payment links/reminders, schedules follow-ups, and shows what the agent learned about each borrower.

For the hackathon, the goal is to build a convincing end-to-end demo, not a production-ready collections system. Keep a few obvious safety rails, but bias toward a working product loop.

## Hackathon Principle

Show an agent that can recover money before breach by reasoning over borrower context, negotiating a practical payment, and turning the agreement into a payment action.
